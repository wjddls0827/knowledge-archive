# 작업 큐 (대시보드·수집 개선)

사용자 지시를 큐로 쌓아 하나씩 처리. 아래 '완료'는 검증(파싱/테스트/부팅)까지 끝낸 것.

## ✅ 완료
| # | 작업 | 비고 |
|---|---|---|
| 1 | 원문 잘림 방지 | 추출 텍스트 `[:20000]` 4곳 제거(app·service·cli). |
| 2 | '나란히 보기' 버튼 일관화 | 유형 공통 규칙으로 통일. (→ 2b에서 더 정리) |
| 2b | '나란히 보기' 중복 제거 + 번역 있을 때만 | PDF는 페이지번역이 곧 나란히(버튼 1개). 번역 없으면 버튼 숨김. |
| 3 | 메모 자동기입 제거 | 에이전트 수집경위 → `provenance` 분리, 기존 2건 이전, 메모=사용자전용, 프롬프트·CLAUDE.md 규칙화, 대시보드 '🤖 자동 수집 메모' 표시. |
| A | (즉석) 글자 크기 하한 완화 | 11~28px → 8~34px. |
| B | (즉석) 나란히 보기 줌 여백 버그 | 왼쪽만 줄던 것 → `.sidewrap` 전체 스케일. |

| ~~9~~ | ✅ **원문↔번역 문단 정렬** | html 자료 side=문단정렬 리더(원문│번역 행 맞춤). segments 있으면 정확, 없으면 문단(\n\n) 인덱스 폴백. 백엔드 segments 지원(cli·PATCH·프롬프트). scion 아티클 103:103 정확 매칭. PDF는 페이지단위(이미지라 문단정렬 불가 → 8번 필요). |
