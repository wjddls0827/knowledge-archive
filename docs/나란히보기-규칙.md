# 나란히 보기(원문·번역 대조 뷰) 규칙 — 확정본

> 상세페이지에서 원문과 번역을 가로로 대조해 보는 뷰의 스펙. 구현은 이 규칙에 맞춘다.

## 1. 노출 조건
- **번역이 있을 때만** "나란히 보기" 버튼을 보여준다. 번역이 없으면 버튼 자체가 없다.
  - 웹/이미지: `extensions.translation`(또는 `segments`) 존재.
  - PDF: 페이지별 번역(`extensions.pages[].ko`)이 하나라도 존재.

## 2. 좌측 '원문'은 타입별 최적으로 (확정: 타입별 최적)
| 타입 | 좌측(원문) | 우측(번역) | 짝/정렬 단위 |
|---|---|---|---|
| 웹/HTML | 원문 추출 텍스트(문단) | 번역 문단 | **문단 단위 행 맞춤** (segments 있으면 정확, 없으면 문단 인덱스) |
| PDF | 페이지 이미지(derived page-NNN) | 그 페이지 번역(ko) | **페이지 단위 행** |
| 이미지 | 그 이미지 | 설명·번역 | 단일 쌍 |

- 각 짝은 **같은 높이에서 시작**(`align-items:start`).

## 3. 모드(버튼) — 순서 고정 · 기본 나란히
- 순서: **`[원문 스냅/PDF/캡처] [나란히 보기] [읽기 모드]`** (왼→오).
  - 웹: `[원문 스냅샷] [나란히 보기] [읽기 모드]`
  - PDF: `[원문 PDF] [나란히 보기]` (PDF엔 읽기 모드 없음 — 좌측이 이미지라 단일컬럼 텍스트 읽기는 번역 탭으로)
  - 이미지: `[원문 캡처] [나란히 보기] [읽기 모드]`
- **기본 진입 = 나란히 보기** (단, 번역이 있을 때만. 번역 없으면 원문이 기본이고 나란히 버튼도 없음).
- 자료가 바뀔 때만 기본 모드로 리셋 → 편집·자동새로고침 중엔 사용자가 고른 모드 유지.
- "읽기 모드" = 번역을 단일 컬럼으로 읽기(웹/이미지).

## 4. 스크롤
- 나란히는 **한 덩어리로 같이 세로 스크롤**(좌우 독립 스크롤 금지). 문단 행·페이지 행 모두 동일.

## 5. 글자·화면 조절
- **글자(가−/가＋)**: 텍스트 패널 폰트 크기(`--pgfont`, 8~34px). 웹은 양쪽 텍스트, PDF/이미지는 우측 번역.
- **화면(−/＋/맞춤)**: 나란히 블록 **전체를 같이** 줌(한쪽만 줄지 않음).

## 6. 좌우가 안 맞을 때(폴백)
- 웹에서 문단 수가 원문≠번역이면: 맞는 데까지 행 맞추고, 남는 문단은 해당 열에 이어 붙인다. (segments가 있으면 애초에 안 생김)
- PDF에서 특정 페이지 ko가 없으면: 그 페이지 우측은 "(이 페이지 번역 준비중)".
