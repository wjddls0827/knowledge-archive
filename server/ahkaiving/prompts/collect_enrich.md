AH!chiving: 이미 보관된 자료 id={{IID}} 를 번역·보강해줘. 본문은 `curl -s http://127.0.0.1:8800/api/materials/{{IID}}` 의 extensions.text(없으면 original_files 원문을 직접 읽어). 자연스러운 한국어 번역(문단 유지) + 요약(아래 HTML 포맷) + 키워드 5개를 만들어 임시 payload.json(키: translation, summary, tags)에 쓰고 summary는 '핵심→근거→함의' 구조의 HTML로: <p><b>한 줄 요약</b><br>…</p><p><b>핵심 포인트</b></p><ul><li>…</li>(2~4개)</ul><p><b>왜 중요한가</b><br>…</p>. `curl -s -X PATCH http://127.0.0.1:8800/api/materials/{{IID}} -H "Content-Type: application/json" --data-binary @payload.json` 로 저장해줘. 이미지 자료면 원문을 보고 내용 설명을 만들어. 본문 안에 원문 출처·참고/영상 링크가 있으면 각 링크를 `curl -s -X POST http://127.0.0.1:8800/api/materials/{{IID}}/attachments/link -H "Content-Type: application/json" --data-binary '{"url":"...","title":"표시명"}'` 로 첨부에 추가해(사용자가 올린 기존 첨부는 보존·append). 원문의 제목 위계는 markdown 헤딩(#·##·###), 목록은 '- ' 불릿으로 보존하고, 도식·차트가 있으면 mermaid/markdown 표로 재구성해 번역에 포함. 원문↔번역 나란히 정렬을 위해 'segments'(원문 문단과 그 번역을 쌍으로: [{"o":원문문단,"k":번역문단}, …], 문단 수·순서 일치)도 함께 넣어줘. 수집 경위·판단(번역 생략 이유, 날짜 추정 근거, 댓글 수집 통계 등)은 payload의 'provenance' 키에 적어. 'notes'(메모)는 사용자 전용이라 절대 쓰지 마(비워 둬). {{STAGE_HINT}}
