AH!chiving 아카이빙 수집 작업이야. 아래 링크를 WebFetch로 가져와서 원문 본문 추출 + 자연스러운 한국어 번역(문단 구분 유지) + 요약(아래 HTML 포맷) + 키워드 5개 + 저자/발행일을 만들고, summary는 '핵심→근거→함의' 구조의 HTML로: <p><b>한 줄 요약</b><br>…</p><p><b>핵심 포인트</b></p><ul><li>…</li>(2~4개)</ul><p><b>왜 중요한가</b><br>…</p>. 원문의 제목·소제목 위계는 markdown 헤딩(#·##·###), 목록은 '- ' 불릿으로 text·translation에 보존해(대시보드가 렌더). 원문에 도식·차트·표가 있으면 비워두지 말고 mermaid 코드블록(```mermaid```)이나 markdown 표로 재구성해 해당 위치에 포함. 그리고 페이지 **전체(스크롤 끝까지, full-page) 스크린샷**을 떠서 — 한 화면(뷰포트)만 찍지 말고 문서 전체 높이를 한 장에 담아 — 이미지 파일로 저장하고 payload의 'thumbnail'(그 파일경로)로 넘겨(원문 캡처·썸네일 공용). 전체 캡처가 안 되는 도구면 가능한 한 길게(여러 번 찍어 세로로 이어 붙여도 좋음). payload를 임시 JSON 파일로 써서 `python -m ahkaiving.cli ingest <그_json경로>` 로 보관해줘. payload 필드/스키마 정본은 ahkaiving/domain/payload.py 참고(url,title,kind,authors,published_at,text,translation,summary,tags 등). 이게 **채용공고(JD)**면 kind='jd' 로 하고, 지원 **마감일**을 payload 'deadline' 로 꼭 넣어줘 — 공고에 마감 날짜가 조금이라도 적혀 있으면 **반드시 그 날짜를 'YYYY-MM-DD'로**(예: '~11/20', '11월 20일 마감', 'D-7' → 실제 날짜로 환산). 공고에 '상시채용·수시채용·채용 시 마감'이라고 **명시된 경우에만** '상시'. 날짜도 없고 상시도 아니면 넣지 마 — 날짜를 못 찾았다고 섣불리 '상시'로 적지 말 것. 본문 안에 '원문 출처 링크'나 따로 첨부된 영상·파일 링크가 있으면 payload의 'attachments'=[{"kind":"link"|"video","name":표시명,"url":주소}] 에 넣어줘(첨부 탭에 북마크 카드·영상 미리보기로 뜸). 광고·내비·추천 말고 본문이 실제로 가리키는 원문/참고 링크만. 원문↔번역 나란히 정렬을 위해 'segments'(원문 문단과 그 번역을 쌍으로: [{"o":원문문단,"k":번역문단}, …], 문단 수·순서 일치)도 함께 넣어줘. 수집 경위·판단(번역 생략 이유, 날짜 추정 근거, 댓글 수집 통계 등)은 payload의 'provenance' 키에 적어.
